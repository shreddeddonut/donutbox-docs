# Scripts

Full scripts, ready to copy.

## Adding a script

1. Create a page: `docs/scripts/<name>.md`
2. Wrap the script in a fenced code block (the copy button appears on hover):

   ````markdown
   # My Script

   ```bash
   #!/bin/bash
   echo "hello"
   ```
   ````

3. Add it to the `Scripts` nav in `mkdocs.yml`
4. Commit and push to `main` - the site rebuilds automatically
