# Obsidian

A knowledge base that works on local Markdown files. Notes are plain text on
your disk, with backlinks, a graph view, and a plugin ecosystem.

## Why it's good

- Your notes are plain Markdown files — no lock-in, no proprietary format.
- Backlinks and the graph view make connections between notes visible.
- Huge plugin ecosystem for everything from kanban to spaced repetition.

## How to use it

- Create a vault (a folder of `.md` files) and open it in Obsidian.
- Link notes with `[[Note Name]]`.
- Sync the vault folder with any file-sync tool — it's just files.

## Notes

- Free for personal use. Available on macOS, Windows, Linux, iOS, Android.
- The vault is portable: point any Markdown tool at the same folder.
