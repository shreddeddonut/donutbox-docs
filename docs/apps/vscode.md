# VS Code

A free, open-source code editor. Extensible, cross-platform, and the default
choice for a huge share of developers.

## Why it's good

- Huge marketplace of extensions for every language and workflow.
- Built-in Git integration, terminal, and debugging.
- Runs on Windows, macOS, and Linux.

## How to use it

- Install extensions from the marketplace: language servers, themes, linters.
- Use the integrated terminal and Git panel to stay in one window.
- `code .` opens the current directory from the terminal.

## Notes

- Free and open source (MIT for the core).
- The `code` CLI is worth adding to your PATH for terminal-driven workflows.
